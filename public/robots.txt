# robots.txt for joshblewitt.dev

# This file is a request, not an enforcement mechanism: well-behaved crawlers
# honour it, and everything else ignores it. Enforcement lives in the Vercel
# firewall. The two work together — with AI bots set to "log" rather than
# "deny" there, the firewall logs show which crawlers actually respect the
# rules below and which ignore them.
#
# Note on precedence: a crawler obeys the MOST SPECIFIC group matching its
# user-agent and ignores every other group, including "*". That is why each
# named group below repeats the private-path rules rather than inheriting them.

# ---------------------------------------------------------------------------
# Default — open, except for surfaces that are not readable content.
# ---------------------------------------------------------------------------

Disallow: /owner/
# Comment, auth and search endpoints. /rss.xml and /sitemap.xml are internal
# rewrites to /api/*, but crawlers request the public paths, so this does not
# hide the feed or the sitemap.
Disallow: /api/

# ---------------------------------------------------------------------------

#
# Google-Extended and Applebot-Extended are not crawlers — they are opt-out
# tokens that govern whether content already fetched by Googlebot/Applebot may
# be used for AI training. They belong here, not in the allowed groups.
