Last month, my [brother](https://matt.blwt.io/) sent me this [blog post](https://shumer.dev/something-big-is-happening) by Matt Shumer. It got me thinking, were my skeptical views on artificial intelligence outdated? What will the end of the year look like? Where do I fit in this ever changing jigsaw puzzle? What role could I do? All important questions.

In the post, Matt Shumer suggests subscribing to ChatGPT or Claude, spend one hour a day experimenting with AI and start using AI at work. So I did exactly that. I subscribed to Claude Pro, experimented with it, and started to use AI more at work (which in this case, my workplace uses CoPilot). I even completed a Google AI Professional course that’s on [Udemy](https://www.udemy.com/partner/google/learn-ai/), which came with three months of Google AI Pro.

And I am genuinely concerned about the future. Because from what I have seen what this technology can do right now makes me question what the next twelve months look like. Not the next five years, but the next twelve months. This technology is making progress at a terrifyingly fast pace, and I can’t say or predict what the world will look in a few years time.

My opinions on AI came from models that were available in 2023 and 2024. Back then these models would struggle with image generation, hallucinate and the technology just didn’t seem that impressive. But now it’s completely different, these models that are now available are far more capable.

Look at this post from [OpenAI](https://openai.com/index/introducing-gpt-5-3-codex/) about the release of GPT-5.3-Codex:

> GPT‑5.3‑Codex is our first model that was instrumental in creating itself. The Codex team used early versions to debug its own training, manage its own deployment, and diagnose test results and evaluations—our team was blown away by how much Codex was able to accelerate its own development.
> 

This model helped build *itself.*

This is no longer something you’d read in a science fiction book, this is really happening in our lifetime.

Let me explain what I’ve been doing with AI recently, and how it’s reshaped my view on the technology.

## Claude Code

I enjoy programming as a hobby. I like working on this website, and a few other projects like a haiku checker or an application that fetches an image from NASA’s astronomy picture of the day and allows a user to ask a question about it. And I have in the past used AI to help me solve some problems that I got stuck on, like adding pagination to this website.

But what if I handed over all the development to Claude Code?

So I did exactly that. I have two projects that were entirely created by [Claude Code](https://claude.com/product/claude-code):

- [Prism](https://github.com/JB-26/prism) - an application that allows you to upload CSV files, that are then analysed by Claude, to create an interactive chart and executive summary.
- [Claude Stocks App](https://github.com/JB-26/claude-stocks-app) - an application that allows users to find stock prices, show historical prices in a chart, news about the company and view multiple stocks.

These applications are on GitHub, feel free to take a look and run them locally.

Creating these applications was not as simple as typing in a prompt which said *“make me a cool stocks app and make no mistakes.”* I wrote a detailed markdown file, which utilised my programming and software development lifecycle knowledge, that contained:

- an executive summary
    - the core flow
- Technical considerations
- User Experience & Styling
- Questions
- User Stories

I then gave this file to Claude and the relevant agents to plan the application, implement features and test it. The end result was that it could build these applications better than I can, which took me by surprise.

Across both applications, there were instances when I discovered bugs with what it had developed. I went back to the Claude, described what the issue was, went away for a few minutes and the issue was fixed when I came back and checked on it.

I went further, I begun creating new agents to automate more tasks, and eventually I had a strong set of agents created:

- Frontend craft
- Product owner strategist
- QA strategist
- Security auditor
- Solution architect
- TypeScript code architect

Since prompts go through tokens and fill up the context window for Claude, using agents helps reduce pollution to Claude’s main context window as each agent gets their *own* context window. This makes agents useful at specific tasks and prevents Claude from forgetting things as well as making mistakes. Creating agents was as simple as providing a brief description of what I wanted the agent to do, and then Claude would fill in the rest.

It’s important to note that these models are only as good as their training data, and have specific cut-off dates. This is an issue when working with frameworks and databases that are constantly being updated. This is where Model Context Protocol (MCP) servers come in. MCP servers allow models like Claude to reference up to date documentation. I use [context7](https://context7.com/) as my MCP of choice, and getting Claude (and agents in Claude) to work with context7 was very easy. I just included ‘use context7’ in the prompt or agent definition and then it would go and retrieve the latest documentation for what I wanted from the MCP server.

When I created the security auditor agent, I wanted to make sure it pulled from the latest known OWASP top 10 list of security vulnerabilities. So when describing the agent, I specifically told it to fetch the latest list from context7. Now the agent has up to date information, and can make suggestions with the latest security issues in mind.

I let Claude Code and a few of the agents I had created explore the code base for this blog and to make suggestions for possible features and fixes. It’s impressive that it can read and understand someone else’s code without it asking questions. The product owner strategist discovered several new features that could be implemented easily, such as the estimated reading time for each post.

Creating application with Claude Code really was the first time I realised what impact this could have on jobs. I could create sophisticated software by simply describing it, let Claude work on it, and then it was ready for me to look at. These tools are better than me, and all I had to do was to create some agents, describe what I wanted and orchestrate the agents to build the software. Sure, I did have to provide plenty of context to Claude before it went ahead and developed what I wanted, but what does the future hold for software development jobs? Will there be fewer entry level roles?

Anthropic’s CEO [said in 2025](https://uk.pcmag.com/ai/158311/anthropic-ceo-ai-poised-to-wipe-out-50-of-entry-level-jobs-in-next-5-years) that AI could eliminate 50% of entry level jobs in the next five years. I think this number might be slightly conservative. In the UK, [unemployment has risen](https://www.bbc.co.uk/news/articles/c1l7pedyzjeo) to it’s highest rate in nearly five years to 5.2%, with 16.1% of young people being unemployed. I imagine that this number will only increase as the year progresses.

## CoPilot (and AI in general) at work

I’ve been trying to use [CoPilot](https://www.microsoft.com/en-gb/microsoft-365-copilot), the tool built by Microsoft, more in my job recently (as that’s what the company I work for uses). The best way to describe my experience is that it’s *fine* (apart from a worrying [bug](https://www.bbc.co.uk/news/articles/c8jxevd8mdyo) that was found)*.* It’s nowhere near as good as Claude in my view, but it eventually gets the job done.

Using AI in my work however does make specific tasks easier:

- analysis
- research
- organisation

These are tasks that I do quite frequently in my job, and AI does improve how fast I can get these tasks done. I always check the output from AI as I want to ensure what it provides is accurate, and sometimes I will ask if it can provide sources or explain in more detail how it came to it’s conclusion.

I will say that CoPilot in Excel is probably one of the weakest and most disappointing experiences I have had with AI. At times it will over complicate what I was asking for, or get it wrong entirely, which is when I will go and do it myself.

I do think that over time, using these tools at work will improve and get better. Which once again raises the question on what will happen to jobs (both entry level and senior) as AI improves. What will my role be if AI can interact with my machine and do my job? What new jobs, if any, are created to replace the ones that are eliminated?

## Other concerns on AI

### Cognitive offloading

When I was in school, my teachers would always warn against copying and pasting from Wikipedia when it came to homework. Obviously because not everything on Wikipedia is true but also you wouldn’t learn anything. Now with AI, you can ask a question and let it do the work for you. These are examples of cognitive offloading, and this is a genuine concern that I have as we begin to use and rely on these systems more. Will we think for ourselves in the future? What about our ability to solve problems?

However, if you ever wanted to learn a new skill, language, discover a new hobby or want advice on starting a business, then applications like Claude are available twenty four hours a day who will help you. And if you subscribe to Claude or ChatGPT then you can use more advanced models to help tackle complex problems you may face. If these systems are used correctly to help us rather than replace us, I think we’re going to be able to solve some complex challenges that face us in the future.

### Protecting the arts and human creativity

Images, text, videos, and music can now all be created by AI through a prompt. This raises obvious concerns as these AI generated assets could be used to manipulate and mislead people. Then there is the concern that human creativity is being replaced by models that lack that creative spark. A horror novel had it’s release [cancelled](https://www.bbc.co.uk/news/articles/c5y9d44jj24o) over concerns that AI was used to help write the book.

There has been a rise in organisations that are creating labels to help people identify if a product or service was made by humans, as the backlash grows against the use of AI. People are worried that entire professions could be eliminated due to this technology, and this is a view that I share.

Some examples of these organisations include:

- [no-ai.com](https://no-ai-icon.com/)
- [AI-free.io](https://ai-free.io/)
- [notbyai.fyi](https://notbyai.fyi/)
- [Books by people](https://booksbypeople.org/)
- [ProudlyHuman](https://www.proudlyhuman.org/)

I strongly believe that human creativity is something that should be protected from AI. One of my favourite websites is YouTube, and I enjoy watching videos from my favourite creators who are passionate about a hobby, a profession and so on. I appreciate the work that they put in to create each video, as I know it isn’t an easy process and that work should be admired and respected. I wouldn’t enjoy it as much if I found that majority of the videos on the platform were created by AI, as it takes away from the human effort to research, produce, and edit a video from start to finish.

A recent example of where human creativity is being preserved and respected is [Games Workshop](https://www.warhammer.com/en-GB/home). The company decided to [ban](https://www.ft.com/content/82bf41f4-7020-4c41-9ca6-f5b7390e9198?gaa_at=la&gaa_n=AWEtsqdi-H4iaEs0Q7Ubv-FhbdS57HW1KgPuzsqHTZNcuMHi3GzzrG3vH7X9zrF-dj8%3D&gaa_sig=ysZS7IBhLAvBj1Uj1B6ukG43K2GOUTZQyE-LNY1Rz37sR2YFu32YGAqOrCSFpFTDrz1paoGEps9gKy07SB28LQ%3D%3D&gaa_ts=69667453&syn-25a6b1a6=1) the use of AI in it’s designs. The chief executive of the company said that they were not an expert in the technology, *“We do have a few senior managers that are: none are that excited about it yet.”*

### Remembering what AI is

Last year I attended a conference where the main topic was AI, and there was a panel session that had an engineering manager who made some good points about how we should think about this technology:

- AI being a tool to help us is a common theme
- AI is just software
- Always understand the business problem
- We should be cautious when it comes to using AI
- We should question AI

Another interesting point that was made was that although there is a huge amount of hype around AI, we need to remember who is marketing this technology to us. The answer is that the companies behind this technology are marketing AI to us aggressively.

As this technology continues to improve, we should not forget that we must always question the output, why we’re using the technology in the first place and what impact this is having not just on our work, but on society as a whole.

### Whatever AI generates, we own it

If there’s something that we need to remember, it’s that although we can write prompts into a system like Claude or ChatGPT and use whatever it generates, we are still responsible for how the generated asset is used. We cannot just blame the model, that remains with us.

Amazon had an [incident](https://www.businessinsider.com/amazon-tightens-code-controls-after-outages-including-one-ai-2026-3?op=1) that was caused by their own AI development tool called Q. This led to the company to introduce new guardrails which would combine agentic development with more predictable rules based systems.

However, this does raise the question of who will be responsible for owning what this technology creates if jobs are eliminated?

### What about the AI bubble? Will it pop?

This is a tricky question to answer, the debate about if this is a bubble and when it will pop has been ongoing for a while now. And yet companies like [NVIDIA](https://www.nvidia.com/en-gb/) continue to make incredible amounts of money from the technology, and are investing in it constantly.

Now, *if* it did pop, then I could imagine a lot of people would lose a lot of money. But from what I can see at the moment is that the development of this technology isn’t slowing down and the investments keep coming.

Larry Fink, the boss of financial giant [BlackRock](https://www.bbc.co.uk/news/articles/c9wqrdkx8ppo), believes we are not in a bubble, and one of the biggest obstacles for the expansion of AI in Europe and the US is the cost of energy, and that investing in solar will result in cheap and inexpensive power for this technology.

Elsewhere, OpenAI announced that its video generating application, [Sora](https://www.wired.com/story/openai-shuts-down-sora-ipo-ai-superapp/), is shutting down after being unveiled in 2024. The company will also wind down the $1bn partnership with Disney. There were genuine questions as to how this service would make money, as it is extremely expensive to generate videos. I don’t think this is a sign of the bubble popping *yet,* it’s too early to tell what impact this will have.

## What should we do?

The advancements in AI is a genie out of the bottle situation. The technology is here, and it’s not going away anytime soon.

These are my thoughts to some questions that I’ve had and some general advice as we work our way through this period of change.

### Start using it more often, and more seriously

Matt Shumer recommended this, and it’s something that I agree with. Take a look into subscribing to either Claude, Gemini or ChatGPT. Start using it for tasks, projects and go outside your comfort zone. Start using it in your work, find how it can improve your work. You’d be surprised at how capable AI can be when it comes to work, just keep in mind that you should always check the output of it, these models can make mistakes.

Is there something you want to do in your house? Send the model a picture of what you want to do, delegate the tasks between yourself and the model and see what happens! The vision capabilities of these models is quite impressive now. I found that experimenting with AI is a good way in truly understanding it’s capabilities and weaknesses.

If you find opportunities at work, take advantage of the situation and start using it as much as possible. Finding ways on how you can improve your work with AI is looking to be a useful skill to have in the near future.

### Not sure how to use AI effectively? Sign up to a course

Many people treat AI as a search engine, and might not fully understand what the hype is about when it comes to the technology, or aren’t sure how to fully use it. This can limit what people think of AI as it can be a disappointing experience by treating it as a search engine, rather than a thinking partner. If you relate to this, I strongly urge you to take a course and see what this technology can really do.

The Google AI professional course that’s on [Udemy](https://www.udemy.com/partner/google/learn-ai/) is a great place to start learning how to use AI for tasks and it comes with Google AI Pro for three months. You can include the certification in your LinkedIn profile and on your CV or resume.

I’d recommend this course as it gives you experience in seeing what Gemini can generate from text, to videos and applications. It provides work like scenarios for you to experience and you get to work with models like nano banana for image generation. The bundled Google AI Pro subscription gives you time to practice and work with AI afterwards by using more advanced models.

I know it sounds weird to suggest doing a course, you might think you know everything when it comes to AI. But believe me, you don’t. Writing prompts that return the desired result takes time and practice. Going through the course and seeing how it works will open your eyes to what’s possible.

If you want to look at more of the theory behind this technology, I can also recommend doing the [AI Fluency: Framework & Foundations](https://anthropic.skilljar.com/ai-fluency-framework-foundations) by Anthropic (the developers of Claude), the course is free!

### Know how AI will impact your profession

This is important, remember how the CEO of Anthropic said that 50% of white collar jobs will be eliminated in the next five years? Do you believe that your career won’t be impacted by AI? I’ve spoken about software engineering, but what about fields such as finance, education, marketing, medicine, and so on. 

And if you believe you could be, take time to think and build a strategy of what your next move will be. Don’t just think about your career, think about your finances as well. Can you transition into a new role? Have you thought about starting your own business?

### Watch for developments

Read tech blogs, magazines, news posts from the developers of AI, videos, newsletters, you name it, do whatever it takes to remain informed by any new developments in this space. This area is constantly changing, and being informed on the latest news is becoming incredibly important.

The time to take action is *right now*.
